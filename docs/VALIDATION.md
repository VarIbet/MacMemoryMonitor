## 尚需实机人工验收

原生界面工具可以读取活动监视器，但按名称、bundle ID 和路径连接新建应用均超时，无法自动确认应用界面的实际点击效果。下列项目已实现，但不能标记为已完成端到端验收：

- 菜单栏彩色圆点及数字的实际 Retina 外观、点击弹出 / 点击外部关闭、跨屏幕及菜单栏隐藏时行为。
- 面板内容布局、图表持续更新、排行榜刷新、打开活动监视器按钮、设置窗口显示。
- 四档刷新间隔、单位、精度、深浅外观的交互与重启持久化。
- 登录项真实开启 / 关闭，以及重新登录自动启动。测试没有改变用户登录项。
- 通知授权及真实持续 Critical 压力提醒。测试没有请求用户通知权限或人为制造系统内存压力。
- 真实睡眠 / 唤醒，以及 24 小时以上的稳定性和泄漏检查；历史算法测试不能替代这些测试。
- 面板按钮退出后无残留进程；仅验证过测试实例由 TERM 终止后消失。

建议人工顺序：启动 → 查看面板与系统数据 → 修改刷新、精度和外观 → 退出重启验证保存 → 放到 Applications 再测登录项 → 正常休眠唤醒 → 观察长时间资源变化。通知和登录项均保持默认关闭，按需要主动开启。
